# Temple of the Lost Wilds

A first-person, solo, arcade-style endless runner in a low-poly fantasy wilderness with a pulp-adventure
(Indiana Jones-style) theme. Run through ancient ruins, leap logs and pits, slide under stone beams,
grab golden idols, and outrun the boulder: every mistake lets it gain on you.

Open `index.html` in a browser (needs internet for the Three.js CDN), or serve it: `python3 -m http.server`.

Controls: A/D or ←/→ change lane · W/↑/Space jump · S/↓ slide · touch: swipe.
